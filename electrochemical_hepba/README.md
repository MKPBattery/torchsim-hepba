# 电化学沉积法制备HEPBA材料的模拟研究

## 项目概述
本项目旨在模拟电化学沉积法制备高熵普鲁士蓝类似物（HEPBA）的过程，包括电解液组成、电极界面反应、成核生长等多个方面。

## 模拟内容
1. 电解液体系
   - 金属离子配位环境
   - pH缓冲效应
   - 络合平衡

2. 电极界面过程
   - 电子转移动力学
   - 金属离子还原
   - 成核生长机制

3. 薄膜形成过程
   - 晶体结构演化
   - 界面结合特性
   - 形貌发展

## 实验参数
- 金属离子：Cu²⁺, Fe³⁺, Mn²⁺, Ni²⁺, Co²⁺ (各0.2 M)
- 络合剂：柠檬酸钠
- 缓冲液：硼酸 (0.162 M)
- 支持电解质：硫酸铵 (0.05 M)
- pH：3.5
- 温度：30 °C

## 电沉积条件
1. 恒电流法
   - 电流密度：20 mA/cm²
   - 时间：60分钟

2. 循环伏安法
   - 电位范围：-0.4 V ~ 1.3 V
   - 扫描速率：20 mV/s
   - 循环次数：200圈
